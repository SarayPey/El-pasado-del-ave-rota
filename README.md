*«En la lejanía de nuestro mundo, en Mochu, un ave herida sanaba sus alas rotas».*

Eres un agente de la policía de Senlín; junto con otros agentes, planifican una misión a un laboratorio.

---

# CARACTERÍSTICAS DEL JUEGO:

- Diseños, código, gráficos y música creados por una persona.

- Una historia de fantasía con trasfondos sobre el control del tiempo.

- Capítulos publicados con cada nueva versión grande.

- Variados finales para desbloquear.

- Rutas especiales.

- (PRÓXIMAMENTE) Sistema de tienda y galería.

Este juego es para mayores de 15 años, debido a que contiene temas relacionados con el bullying, el acoso, el suicidio y la salud mental. Contiene imágenes brillantes y parpadeantes.
